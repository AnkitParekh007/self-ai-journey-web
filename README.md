# Self AI Journey — public shell

This repository contains only the **data-free frontend shell** of Self AI Journey and its
original learning content (question banks, study notes, course links, portfolio project specs).

- No personal data, applications, documents, recruiter notes or salary information is included.
- The site is public. Anything you enter stays in **your browser** (IndexedDB) unless you
  connect your own **private** repository with a fine-grained token (kept in memory only).
- Local browser data is sensitive: use "Clear local data" on shared computers. Disconnecting a
  token does not delete cached records.

Built from the private source repository by an allowlisted export with a canary check.
